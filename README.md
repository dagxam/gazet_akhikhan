# AKHIKHAN.RU

Сайт местной газеты **AKHIKHAN.RU**.

Стек первой версии: PHP 8+, MySQL/MariaDB, HTML/CSS/JS без обязательных внешних фреймворков.

Проект строится по схеме **GitHub → FTP/хостинг**. Исходный код хранится в этом репозитории, а публикация на сайт будет выполняться после настройки FTP-деплоя.

## План
- Главная страница в газетном стиле.
- Рубрики, статьи, поиск и просмотры.
- Адаптивная версия для телефона/планшета/ПК.
- Собственная админ-панель.
- Управление статьями, рубриками, настройками сайта и блоком «Слово редактора».
- Безопасная авторизация, CSRF-защита, PDO prepared statements.
- SEO-friendly URL, sitemap/RSS — следующим этапом.

> Конфигурация БД и FTP-секреты не должны попадать в репозиторий.
